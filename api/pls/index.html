    PLS-DA

    Partial Least Squares Discriminant Analysis with double cross-validation.

    Scale and nuisance residualization

    plsda_doubleCV takes five keyword-only arguments whose defaults reproduce its earlier behaviour exactly:

    • scale (default True) is passed to every PLSRegression fit in the inner loop, the outer loop and the per-repeat refits. False fits in the metric the predictors are already in, for example pooled-standardized features that must keep their pooled scale.
    • nuisance (default None) takes a NuisanceDesign: row-aligned conditioning columns D (no intercept) and covariate columns C. Every training set (each outer rest set and each inner training set) regresses its predictors on [1, D, C], subtracts the fitted covariate part C γ, and residualizes its held-out rows as X_held_out − C_held_out γ. The held-out rows' conditioning (their labels) is never read. The per-repeat refits use coefficients estimated on all rows. Every training design must have full column rank, or the function raises a ValueError naming the repeat and fold, for example when a factor level is absent from a training set. The result gains "nuisance_min_training_df", the smallest training-set residual degrees of freedom.
    • strata (default None) names row-aligned labels both CV levels stratify on instead of y; the AUROC still scores y. Folds depend only on the partition the labels define, so labels that partition the rows like y reproduce the default folds. With a nuisance design, pass nuisance.cells() (its conditioning cells) so every training set contains every cell: the inner folds are not shuffled, and on rows sorted by group within stage a stage-only stratification can put a whole group × stage cell into one validation fold.

    • min_components (default 1) is the smallest number of latent variables the inner CV considers: the candidates are min_components … max_components − 1, so every outer-fold selection, every modal LV in the table and every refit model has at least that many components. It must satisfy 1 ≤ min_components < max_components, or the function raises a ValueError naming both values before any fold is fitted. The default is the unfloored rule; the trajectory latent space (fit_pls_latent_space, shared by the simulation harness and motco analyze) applies a floor of 2 by default, see Real-data analysis.

    • sparsity (default None) takes a SparsityDesign and selects a sparsity budget jointly with the rank; see below.

    The real-data analysis uses scale, nuisance and strata together for covariate-aware latent construction; see Real-data analysis.

    Sparse PLS-DA

    SparsePLSDA (motco.stats.sparse_pls, also importable from motco.stats) is a PLSRegression whose components each load on a budget of features (the sPLS-DA of Lê Cao et al., regression mode). Inside scikit-learn's NIPALS power iteration the X weight vector is soft-thresholded before it is normalized: the largest absolute weights are kept and shrunk toward zero by the largest discarded one, and every other weight is zero. Everything else is scikit-learn's: the model inherits transform, inverse_transform, predict, x_rotations_, x_scores_ and the input scaling, so every consumer of a fitted PLS-DA model in MOTCO (the latent map, span capture, attribution, VIPs, the split test) accepts it unchanged. At the full budget the fit is PLSRegression.fit, bit for bit. keep_ holds the count per component and group, support_ the non-zero weights (features × components). The fit agrees with mixOmics splsda on the committed fixture (tests/data/splsda_reference_fixture.npz, produced once by tests/data/reference/splsda_fixture.R): identical supports, weights and scores to 1e-6 up to column signs.

    A SparsityDesign(scope, keep_fractions, feature_groups) describes the budget to select over:

    • scope is "joint" (one budget over all features) or "block" (one budget per block, so every block keeps its share whatever its size; a joint budget on blocks of unequal noise can empty a block). DIABLO's between-block agreement term is not part of it.
    • keep_fractions (default 1.0, 0.5, 0.2, 0.1, 0.05) are fractions of the scope's feature count, distinct and in (0, 1], held fullest first. A fraction keeps max(1, round(f · p)) features per group (halves round up), so every block keeps at least one feature per component.
    • feature_groups are the block sizes in column order; the block scope needs them, and plsda_doubleCV rejects groups that do not cover the columns of X before any fold is fitted.

    With sparsity=, the inner CV scores every (rank, fraction) pair by mean held-out AUROC, ordered rank ascending then fraction descending, so an exact tie goes to the smaller rank and, within it, to the fuller budget: the CV leaves production only on strictly better held-out AUROC. The outer fold is evaluated at the selected pair. Each repeat aggregates the rank by mode (smaller on ties) and the fraction by mode (fuller on ties), the table gains a keep_fraction column after LV, and every refit model is a SparsePLSDA at the repeat's pair. A ladder of [1.0] reproduces the run without sparsity exactly. Without sparsity the output is byte-identical to before (tests/data/plsda_doublecv_identity.json) and has no new column.

    def plsda_doubleCV(
    X: pd.DataFrame,
    y: Union[pd.DataFrame, pd.Series],
    cv1_splits: int = 7,
    cv2_splits: int = 8,
    n_repeats: int = 30,
    max_components: int = 50,
    random_state: int = 1203,
    n_jobs: int = 1,
    progress: bool = True,
    *,
    scale: bool = True,
    nuisance: NuisanceDesign | None = None,
    strata: Union[np.ndarray, pd.Series, Sequence[str], None] = None,
    min_components: int = 1,
    sparsity: SparsityDesign | None = None,
) -> PLSDAResult:
    """
    Run canonical double-nested cross-validation for PLS-DA.

    For each outer fold, the inner CV averages AUROC across its V folds and
    selects the n_LV with the highest mean. The outer fold's selected n_LV is
    then evaluated on its held-out test set. Per repeat, the K outer-fold test
    AUROCs are aggregated by mean (and sample std), and the per-fold n_LV
    choices are aggregated by mode (parsimony tie-break). One final model is
    refit per repeat on the full input using the modal n_LV.

    Parameters
    ----------
    X: pd.DataFrame
        The predictor variables.
    y: Union[pd.DataFrame, pd.Series]
        The outcome variable.
    cv1_splits: int
        Number of folds in the CV1 (inner) loop. Default: 7.
    cv2_splits: int
        Number of folds in the CV2 (outer) loop. Default: 8.
    n_repeats: int
        Number of repeats of the K-fold outer CV. Default: 30.
    max_components: int
        Maximum number of LV to test (candidates are
        ``min_components..max_components-1``). Default: 50.
    random_state: int
        For reproducibility. Default: 1203.
    n_jobs: int
        Number of parallel workers for the inner CV loop. Use -1 for all
        available CPUs. Default: 1 (serial).
    progress: bool
        Whether to display a tqdm progress bar over outer folds. Default: True.
    scale: bool
        Keyword-only. Whether every PLS fit (inner, outer and the per-repeat
        refits) rescales the predictors to unit variance. ``False`` fits in the
        metric ``X`` is already in. Default: True.
    nuisance: NuisanceDesign | None
        Keyword-only. When given (row-aligned to ``X``), every training set —
        each outer rest set and each inner training set — estimates the
        covariate coefficients of ``X`` on ``[1, conditioning, covariates]``
        from its own rows (:func:`fit_nuisance_coefficients`), residualizes its
        own rows, and residualizes the held-out rows with the same coefficients
        and the held-out covariate columns alone, so held-out labels never
        enter the residualization. The per-repeat refits use coefficients
        estimated on all rows. Every training design must have full column
        rank; otherwise a ``ValueError`` names the repeat and fold. Default:
        None (no residualization).
    strata: array-like | None
        Keyword-only. Row-aligned labels the outer and inner folds are
        stratified on instead of ``y`` (for example the conditioning cells of
        ``nuisance``, so that every training set contains every cell). Folds
        depend only on the partition the labels define, so labels that
        partition the rows like ``y`` reproduce the default folds. Default:
        None (stratify on ``y``).
    min_components: int
        Keyword-only. The smallest number of latent variables the inner CV
        considers, so the candidates are ``min_components..max_components-1``
        and every outer-fold selection, every modal ``LV`` and every refit
        model has at least this many components. Must satisfy
        ``1 <= min_components < max_components``; otherwise a ``ValueError``
        names both values before any fold is fitted. Default: 1 (the
        unfloored rule; the trajectory latent space applies its own floor,
        see :func:`motco.simulations.evaluation.fit_pls_latent_space`).
    sparsity: SparsityDesign | None
        Keyword-only. When given, every fit is a
        :class:`~motco.stats.sparse_pls.SparsePLSDA` and the inner CV scores
        every pair of a candidate rank and a keep fraction of the design's
        ladder, ordered rank ascending then fraction descending, so the
        first-occurrence ``argmax`` breaks an exact tie of mean inner AUROC
        toward the smaller rank and, within it, toward the fuller budget. The
        outer fold is evaluated at the selected pair; each repeat aggregates
        the rank by mode (smaller on ties) and the fraction by mode (fuller on
        ties) and refits a sparse model at that pair. The design's feature
        groups must cover the columns of ``X`` (a joint design without groups
        is completed with one group); otherwise a ``ValueError`` is raised
        before any fold is fitted. A ladder of ``[1.0]`` reproduces the run
        without sparsity exactly (the full budget is ``PLSRegression``).
        Default: None (ordinary PLS-DA; byte-identical output, no new column).

    Returns
    -------
    dict
        With two keys:

        - ``"table"``: pd.DataFrame with one row per repeat and four columns —
          ``"rep"`` (int), ``"LV"`` (int, modal across K outer folds with
          parsimony tie-break), ``"AUROC"`` (float, mean across K outer folds),
          ``"AUROC_std"`` (float, sample std across K outer folds; NaN if K < 2).
        - ``"models"``: list of length ``n_repeats``. Each entry is a
          PLSRegression refit on the full input (X, one-hot(y)) with the
          corresponding row's modal n_LV.

        With ``sparsity`` given, the table gains a ``"keep_fraction"`` column
        after ``"LV"`` (float, the repeat's modal fraction) and every model is
        a ``SparsePLSDA`` at the row's rank and fraction.

        With ``nuisance`` given, a third key ``"nuisance_min_training_df"``
        holds the smallest residual degrees of freedom of any training-set
        residualization fit.
    """
    _X_arr = np.asarray(X, dtype=float)
    _y_arr = np.asarray(y)
    _n_x = _X_arr.shape[0]
    _n_y = _y_arr.shape[0]
    if _n_x != _n_y:
        raise ValueError(
            f"X has {_n_x} rows but y has {_n_y} rows — number of rows must match."
        )
    _n_classes = len(np.unique(_y_arr))
    if _n_classes < 2:
        raise ValueError(
            f"y has {_n_classes} unique class(es); at least 2 are required."
        )
    if max_components > _X_arr.shape[1]:
        raise ValueError(
            f"max_components={max_components} exceeds the number of features in X "
            f"({_X_arr.shape[1]}); reduce max_components."
        )
    try:
        floor_ok = int(min_components) == min_components and 1 <= min_components < max_components
    except (TypeError, ValueError):
        floor_ok = False
    if not floor_ok:
        raise ValueError(
            f"min_components={min_components!r} must be an integer with "
            f"1 <= min_components < max_components={max_components}; the candidates are "
            "min_components..max_components-1."
        )
    min_components = int(min_components)
    design: SparsityDesign | None = None
    if sparsity is not None:
        if not isinstance(sparsity, SparsityDesign):
            raise ValueError(f"sparsity must be a SparsityDesign or None, got {type(sparsity).__name__}.")
        design = sparsity.resolve(_X_arr.shape[1])
    if not np.all(np.isfinite(_X_arr)):
        raise ValueError("X contains NaN or Inf values.")
    if nuisance is not None and nuisance.n_samples != _n_x:
        raise ValueError(f"X has {_n_x} rows but the nuisance design has {nuisance.n_samples}.")
    folds_on: Union[pd.DataFrame, pd.Series] = y
    if strata is not None:
        folds_on = pd.Series(np.asarray(strata))
        if folds_on.shape[0] != _n_x:
            raise ValueError(f"X has {_n_x} rows but strata has {folds_on.shape[0]}.")
    encoder = OneHotEncoder(sparse_output=False)
    yd_arr = encoder.fit_transform(np.array(y).reshape(-1, 1))
    yd = pd.DataFrame(yd_arr)
    cv2 = RepeatedStratifiedKFold(
        n_splits=cv2_splits, n_repeats=n_repeats, random_state=random_state
    )
    cv1 = StratifiedKFold(n_splits=cv1_splits)

    # Candidates are (rank, keep fraction) pairs, rank ascending then fraction
    # fullest first; without sparsity the fraction is None (ordinary PLS).
    fractions: tuple[float | None, ...] = (None,) if design is None else design.keep_fractions
    candidates: list[tuple[int, float | None]] = [
        (n_lv, fraction) for n_lv in range(min_components, max_components) for fraction in fractions
    ]
    n_candidates = len(candidates)

    rep_means: list[float] = []
    rep_stds: list[float] = []
    rep_lvs: list[int] = []
    rep_fractions: list[float] = []

    outer_aurocs: list[float] = []
    outer_n_lv: list[int] = []
    outer_fractions: list[float] = []
    fold_in_repeat = 0
    training_dfs: list[int] = []
    auroc = partial(_candidate_auroc, scale=scale, sparsity=design)

    cv2_iter = tqdm(
        cv2.split(X, folds_on),
        total=cv2_splits * n_repeats,
        desc="PLS-DA CV2",
        unit="fold",
        disable=not progress,
    )
    for rest, test in cv2_iter:
        X_rest = X.iloc[rest, :]
        X_test = X.iloc[test, :]
        folds_on_rest = folds_on.iloc[rest]
        yd_rest = yd.iloc[rest, :]
        yd_test = yd.iloc[test, :]
        outer_where = f"repeat {len(rep_lvs) + 1}, outer fold {fold_in_repeat + 1}"
        X_rest_fit, X_test_fit = X_rest, X_test
        if nuisance is not None:
            X_rest_fit, X_test_fit, rest_df = _fit_and_residualize(
                X_rest, X_test, nuisance, rest, test, outer_where
            )
            training_dfs.append(rest_df)

        # Inner CV: average AUROC across V folds for each candidate n_LV.
        inner_aurocs = np.zeros((cv1_splits, n_candidates))
        for v_idx, (train, validation) in enumerate(cv1.split(X_rest, folds_on_rest)):
            X_train = X_rest.iloc[train, :]
            yd_train = yd_rest.iloc[train, :]
            X_val = X_rest.iloc[validation, :]
            yd_val = yd_rest.iloc[validation, :]
            if nuisance is not None:
                # Coefficients from the inner training rows of the raw predictors.
                X_train, X_val, train_df = _fit_and_residualize(
                    X_train,
                    X_val,
                    nuisance,
                    rest[train],
                    rest[validation],
                    f"{outer_where}, inner fold {v_idx + 1}",
                )
                training_dfs.append(train_df)
            args = zip(
                candidates,
                repeat(X_train),
                repeat(yd_train),
                repeat(X_val),
                repeat(yd_val),
            )
            fold_aurocs: list[float]
            if n_jobs == 1:
                fold_aurocs = [auroc(*a) for a in args]
            else:
                n_workers = (
                    (multiprocessing.cpu_count() or 1) if n_jobs == -1 else max(1, n_jobs)
                )
                with multiprocessing.Pool(processes=n_workers) as pool:
                    fold_aurocs = pool.starmap(auroc, args)
            inner_aurocs[v_idx, :] = fold_aurocs

        mean_per_candidate = inner_aurocs.mean(axis=0)
        # np.argmax returns the first occurrence on ties → parsimony (the
        # smaller rank, then the fuller budget). Select by value so the floor
        # is a property of the candidate set.
        candidate_star = candidates[int(np.argmax(mean_per_candidate))]

        outer_score = float(
            auroc(candidate_star, X_rest_fit, yd_rest, X_test_fit, yd_test)
        )
        outer_aurocs.append(outer_score)
        outer_n_lv.append(candidate_star[0])
        if candidate_star[1] is not None:
            outer_fractions.append(candidate_star[1])

        fold_in_repeat += 1
        if fold_in_repeat == cv2_splits:
            mean_auroc = float(np.mean(outer_aurocs))
            std_auroc = (
                float(np.std(outer_aurocs, ddof=1))
                if len(outer_aurocs) > 1
                else float("nan")
            )
            mode_lv = _modal_int_with_parsimony(outer_n_lv)
            rep_means.append(mean_auroc)
            rep_stds.append(std_auroc)
            rep_lvs.append(mode_lv)
            if design is not None:
                rep_fractions.append(_modal_fraction_fullest(outer_fractions))
            outer_aurocs = []
            outer_n_lv = []
            outer_fractions = []
            fold_in_repeat = 0

    model_table = pd.DataFrame(
        {
            "rep": list(range(1, n_repeats + 1)),
            "LV": rep_lvs,
            "AUROC": rep_means,
            "AUROC_std": rep_stds,
        }
    )
    model_table["rep"] = model_table["rep"].astype(int)
    model_table["LV"] = model_table["LV"].astype(int)
    model_table["AUROC"] = model_table["AUROC"].astype(float)
    model_table["AUROC_std"] = model_table["AUROC_std"].astype(float)
    if design is not None:
        model_table.insert(2, "keep_fraction", np.asarray(rep_fractions, dtype=float))

    X_full = _X_arr
    if nuisance is not None:
        try:
            full_coefficients, _ = fit_nuisance_coefficients(_X_arr, nuisance)
        except ValueError as exc:
            raise ValueError(f"Nuisance residualization failed on the full input: {exc}") from exc
        X_full = residualize(_X_arr, nuisance.covariates, full_coefficients)

    best_models: list[PLSRegression] = []
    rep_pairs = zip(rep_lvs, rep_fractions) if design is not None else zip(rep_lvs, repeat(None))
    for lv, fraction in rep_pairs:
        model = _plsda_estimator(lv, scale=scale, sparsity=design, keep_fraction=fraction).fit(X_full, yd_arr)
        best_models.append(model)

    if nuisance is not None:
        return {"models": best_models, "table": model_table, "nuisance_min_training_df": min(training_dfs)}
    return {"models": best_models, "table": model_table}

    model,

    """
    Estimates Variable Importance in Projection (VIP)
    in Partial Least Squares (PLS)

    Parameters
    ----------
    model: PLSRegression
        model generated from the PLSRegression function
    components: Union[None, list[int]]
        if not None, a list of integers indicating the components to compute
        the VIPs from. If None, all components are taken into account.
        Default None.

    Returns
    -------
    vips: np.array
        variable importance in projection for each variable
    """
    if components is not None:
        t = model.x_scores_[:, components]
        w = model.x_weights_[:, components]
        q = model.y_loadings_[:, components]
        p, h = w.shape
    else:
        w = model.x_weights_
        t = model.x_scores_
        q = model.y_loadings_
        p, h = w.shape

    vips = np.zeros((p,))
    s = np.diag(np.matmul(np.matmul(np.matmul(t.T, t), q.T), q)).reshape(h, -1)
    total_s = np.sum(s)
    for i in range(p):
        weight = np.array([(w[i, j] / np.linalg.norm(w[:, j])) ** 2 for j in range(h)])
        vips[i] = np.sqrt(p * np.matmul(s.T, weight)[0] / total_s)
    return vips

    class SparsePLSDA(PLSRegression):
    """PLS regression (PLS-DA on one-hot labels) with a feature budget per component.

    Per component the power iteration's X weight vector is soft-thresholded in
    every group: the ``keep`` largest absolute entries are kept and shrunk
    toward zero by the largest discarded absolute entry, every other entry is
    zero, and the vector is then normalized. Deflation is regression mode, so
    the fitted attributes and methods are those of ``PLSRegression`` with the
    same meanings (``x_rotations_ = W·(PᵀW)⁺``, ``transform``,
    ``inverse_transform``, ``predict``). When every count equals its group's
    size the fit is ``PLSRegression.fit``.

    Parameters
    ----------
    n_components : int, default=2
        Number of components.
    keep : int | sequence of int | None, default=None
        Features each component's X weight vector may load on: one count
        (one group) or one count per group of ``groups``, each in
        ``[1, group size]``. ``None`` keeps every feature, i.e. ordinary PLS.
    groups : sequence of int | None, default=None
        Sizes of consecutive column groups (blocks) the budget is counted in.
        ``None`` is one group of all features.
    scale : bool, default=True
        As :class:`~sklearn.cross_decomposition.PLSRegression`.
    max_iter : int, default=1000
        As ``PLSRegression`` (MOTCO's setting rather than sklearn's 500).
    tol : float, default=1e-06
        As ``PLSRegression``: the iteration stops when the squared change of
        the X weight vector is below ``tol``.
    copy : bool, default=True
        As ``PLSRegression``.

    Attributes
    ----------
    keep_ : ndarray of shape (n_components, n_groups)
        The resolved count per component and group.
    support_ : ndarray of shape (n_features, n_components)
        Boolean; the features each component's weight vector loads on
        (its non-zero entries).
    """

    _parameter_constraints: dict = {
        **PLSRegression._parameter_constraints,
        "keep": "no_validation",
        "groups": "no_validation",
    }

    def __init__(
        self,
        n_components: int = 2,
        keep: int | Sequence[int] | None = None,
        *,
        groups: Sequence[int] | None = None,
        scale: bool = True,
        max_iter: int = 1000,
        tol: float = 1e-06,
        copy: bool = True,
    ) -> None:
        super().__init__(n_components=n_components, scale=scale, max_iter=max_iter, tol=tol, copy=copy)
        self.keep = keep
        self.groups = groups

    @_fit_context(prefer_skip_nested_validation=True)
    def fit(self, X: Any, y: Any) -> SparsePLSDA:
        """Fit the sparse model; the budget is validated before any component is fitted."""

        n_features = int(np.shape(X)[1]) if np.ndim(X) == 2 else -1
        if n_features < 1:
            raise ValueError("SparsePLSDA: X must be a 2-D matrix with at least one column.")
        sizes, counts = _resolve_budget(self.keep, self.groups, n_features)
        if counts == sizes:
            # The full budget: the threshold is zero, so this is ordinary PLS.
            super().fit(X, y)
        else:
            self._fit_sparse(X, y, sizes, counts)
        n_components = self.x_weights_.shape[1]
        self.keep_ = np.tile(np.asarray(counts, dtype=int), (n_components, 1))
        self.support_ = self.x_weights_ != 0.0
        return self

    def _fit_sparse(self, X: Any, y: Any, groups: tuple[int, ...], counts: tuple[int, ...]) -> None:
        """``sklearn.cross_decomposition._PLS.fit`` (regression mode, NIPALS) with the thresholded power method."""

        check_consistent_length(X, y)
        X = validate_data(self, X, dtype=np.float64, force_writeable=True, copy=self.copy, ensure_min_samples=2)
        y = check_array(y, input_name="y", dtype=np.float64, force_writeable=True, copy=self.copy, ensure_2d=False)
        if y.ndim == 1:
            self._predict_1d = True
            y = y.reshape(-1, 1)
        else:
            self._predict_1d = False

        n, p = X.shape
        q = y.shape[1]
        n_components = self.n_components
        rank_upper_bound = min(n, p)
        if n_components > rank_upper_bound:
            raise ValueError(
                f"`n_components` upper bound is {rank_upper_bound}. "
                f"Got {n_components} instead. Reduce `n_components`."
            )
        self._norm_y_weights = False
        Xk, yk, self._x_mean, self._y_mean, self._x_std, self._y_std = _center_scale_xy(X, y, self.scale)

        self.x_weights_ = np.zeros((p, n_components))
        self.y_weights_ = np.zeros((q, n_components))
        self._x_scores = np.zeros((n, n_components))
        self._y_scores = np.zeros((n, n_components))
        self.x_loadings_ = np.zeros((p, n_components))
        self.y_loadings_ = np.zeros((q, n_components))
        self.n_iter_ = []

        y_eps = np.finfo(yk.dtype).eps
        for k in range(n_components):
            yk_mask = np.all(np.abs(yk) < 10 * y_eps, axis=0)
            yk[:, yk_mask] = 0.0
            try:
                x_weights, y_weights, n_iter_ = _sparse_power_method(
                    Xk, yk, groups, counts, max_iter=self.max_iter, tol=self.tol
                )
            except StopIteration as e:
                if str(e) != "y residual is constant":
                    raise
                warnings.warn(f"y residual is constant at iteration {k}")
                break
            self.n_iter_.append(n_iter_)
            _svd_flip_1d(x_weights, y_weights)

            x_scores = np.dot(Xk, x_weights)
            y_ss = np.dot(y_weights, y_weights)
            y_scores = np.dot(yk, y_weights) / y_ss
            x_loadings = np.dot(x_scores, Xk) / np.dot(x_scores, x_scores)
            Xk -= np.outer(x_scores, x_loadings)
            y_loadings = np.dot(x_scores, yk) / np.dot(x_scores, x_scores)
            yk -= np.outer(x_scores, y_loadings)

            self.x_weights_[:, k] = x_weights
            self.y_weights_[:, k] = y_weights
            self._x_scores[:, k] = x_scores
            self._y_scores[:, k] = y_scores
            self.x_loadings_[:, k] = x_loadings
            self.y_loadings_[:, k] = y_loadings

        self.x_rotations_ = np.dot(
            self.x_weights_, pinv(np.dot(self.x_loadings_.T, self.x_weights_), check_finite=False)
        )
        self.y_rotations_ = np.dot(
            self.y_weights_, pinv(np.dot(self.y_loadings_.T, self.y_weights_), check_finite=False)
        )
        self.coef_ = np.dot(self.x_rotations_, self.y_loadings_.T)
        self.coef_ = (self.coef_ * self._y_std).T / self._x_std
        self.intercept_ = self._y_mean
        self._n_features_out = self.x_rotations_.shape[1]
        self.x_scores_ = self._x_scores
        self.y_scores_ = self._y_scores

    def support_sizes(self, groups: Sequence[int] | None = None) -> np.ndarray:
        """Non-zero weights per component (rows) and group (columns); ``groups`` default to the fit's."""

        requested = groups if groups is not None else self.groups
        sizes = (self.support_.shape[0],) if requested is None else tuple(int(size) for size in requested)
        if sum(sizes) != self.support_.shape[0]:
            raise ValueError(f"groups {list(sizes)} do not cover the model's {self.support_.shape[0]} features.")
        bounds = np.cumsum((0,) + tuple(sizes))
        return np.array(
            [[int(self.support_[bounds[g] : bounds[g + 1], k].sum()) for g in range(len(sizes))]
             for k in range(self.support_.shape[1])],
            dtype=int,
        )

    @dataclass(frozen=True)
class SparsityDesign:
    """A sparsity budget to select over: scope, keep-fraction ladder and block sizes.

    ``scope`` is ``"joint"`` (one budget over all features) or ``"block"``
    (one budget per block, so every block keeps its share whatever its size).
    ``keep_fractions`` are fractions of the scope's feature count, distinct and
    in (0, 1]; they are held fullest first. ``feature_groups`` are the block
    sizes in column order; the block scope requires them, the joint scope uses
    them only to report support per block. A joint design without groups is
    completed by :meth:`resolve` once the feature count is known.
    """

    scope: str
    keep_fractions: tuple[float, ...] = DEFAULT_KEEP_FRACTIONS
    feature_groups: tuple[int, ...] | None = None

    def __post_init__(self) -> None:
        if self.scope not in SPARSITY_SCOPES:
            raise ValueError(f"Unknown sparsity scope {self.scope!r}; allowed: {list(SPARSITY_SCOPES)}.")
        if isinstance(self.keep_fractions, (str, bytes)):
            raise ValueError(f"keep_fractions {self.keep_fractions!r} must be a sequence of fractions.")
        try:
            raw = tuple(self.keep_fractions)
        except TypeError:
            raise ValueError(f"keep_fractions {self.keep_fractions!r} must be a sequence of fractions.") from None
        if not raw:
            raise ValueError("keep_fractions must hold at least one fraction.")
        fractions = tuple(_validate_fraction(value, where="SparsityDesign") for value in raw)
        if len(set(fractions)) != len(fractions):
            raise ValueError(f"keep_fractions {list(raw)} repeat a fraction; they must be distinct.")
        object.__setattr__(self, "keep_fractions", tuple(sorted(fractions, reverse=True)))
        if self.feature_groups is None:
            if self.scope == "block":
                raise ValueError("The block sparsity scope needs feature_groups (the block sizes in column order).")
        else:
            object.__setattr__(self, "feature_groups", _validate_groups(self.feature_groups, where="SparsityDesign"))

    @property
    def n_features(self) -> int | None:
        """The total feature count the groups cover (``None`` while unresolved)."""

        return None if self.feature_groups is None else sum(self.feature_groups)

    def resolve(self, n_features: int) -> SparsityDesign:
        """This design checked against ``n_features`` columns (a joint design without groups gets one group)."""

        if self.feature_groups is None:
            return SparsityDesign(self.scope, self.keep_fractions, (int(n_features),))
        if sum(self.feature_groups) != int(n_features):
            raise ValueError(
                f"The sparsity feature groups {list(self.feature_groups)} cover {sum(self.feature_groups)} "
                f"features, but X has {n_features}."
            )
        return self

    @property
    def budget_groups(self) -> tuple[int, ...]:
        """The groups a budget is counted in: the whole feature set (joint) or every block (block)."""

        if self.feature_groups is None:
            raise ValueError("The sparsity design is unresolved; call resolve(n_features) first.")
        return (sum(self.feature_groups),) if self.scope == "joint" else self.feature_groups

    def counts(self, fraction: float) -> tuple[int, ...]:
        """The features kept per budget group at ``fraction``: ``max(1, round(f·p_g))``."""

        value = _validate_fraction(fraction, where="SparsityDesign.counts")
        return tuple(keep_count(value, size) for size in self.budget_groups)

    def estimator(self, n_components: int, fraction: float, *, scale: bool = True) -> SparsePLSDA:
        """An unfitted :class:`SparsePLSDA` at ``n_components`` and ``fraction``."""

        return SparsePLSDA(
            n_components, keep=self.counts(fraction), groups=self.budget_groups, scale=scale, max_iter=1000
        )

    @dataclass(frozen=True)
class NuisanceDesign:
    """Row-aligned nuisance design for covariate residualization.

    ``conditioning`` (``n × k``) holds the design the covariate coefficients
    are estimated conditional on (for example drop-first stage indicators),
    without an intercept; ``covariates`` (``n × q``) holds the covariate
    columns whose fitted part is removed. The residualization regresses each
    predictor on ``[1, conditioning, covariates]`` and subtracts only the
    covariate part, so signal collinear with the covariates but explained by
    the conditioning design is kept (Frisch–Waugh–Lovell). ``kind`` optionally
    names the conditioning design for callers that record it.
    """

    conditioning: np.ndarray
    covariates: np.ndarray
    conditioning_names: tuple[str, ...]
    covariate_names: tuple[str, ...]
    kind: str | None = None

    def __post_init__(self) -> None:
        conditioning = np.asarray(self.conditioning, dtype=float)
        covariates = np.asarray(self.covariates, dtype=float)
        if conditioning.ndim != 2 or covariates.ndim != 2:
            raise ValueError("NuisanceDesign conditioning and covariates must be 2-D matrices.")
        if conditioning.shape[0] != covariates.shape[0]:
            raise ValueError(
                f"NuisanceDesign conditioning has {conditioning.shape[0]} rows but covariates have "
                f"{covariates.shape[0]}."
            )
        if covariates.shape[1] == 0:
            raise ValueError("NuisanceDesign needs at least one covariate column.")
        if conditioning.shape[1] != len(self.conditioning_names) or covariates.shape[1] != len(
            self.covariate_names
        ):
            raise ValueError("NuisanceDesign column names do not match its matrices.")
        object.__setattr__(self, "conditioning", conditioning)
        object.__setattr__(self, "covariates", covariates)
        object.__setattr__(self, "conditioning_names", tuple(self.conditioning_names))
        object.__setattr__(self, "covariate_names", tuple(self.covariate_names))

    @property
    def n_samples(self) -> int:
        return int(self.covariates.shape[0])

    @property
    def column_names(self) -> tuple[str, ...]:
        """Design column names beyond the intercept: conditioning, then covariates."""

        return self.conditioning_names + self.covariate_names

    def matrix(self) -> np.ndarray:
        """The full residualization design ``[1, conditioning, covariates]``."""

        return np.column_stack([np.ones(self.n_samples), self.conditioning, self.covariates])

    def cells(self) -> np.ndarray:
        """One label per row naming its conditioning cell (its distinct conditioning row).

        Under stage indicators these are the stages; under group × stage
        indicators, the group × stage cells. Used to stratify cross-validation
        folds so that every training set contains every conditioning cell.
        """

        return np.array(["|".join(f"{value:g}" for value in row) for row in self.conditioning], dtype=object)

    def rows(self, index: Union[np.ndarray, Sequence[int]]) -> "NuisanceDesign":
        """The design restricted to ``index`` (positional rows)."""

        index = np.asarray(index)
        return NuisanceDesign(
            self.conditioning[index], self.covariates[index], self.conditioning_names, self.covariate_names, self.kind
        )

    def fit_nuisance_coefficients(
    X: Union[np.ndarray, pd.DataFrame],
    design: NuisanceDesign,
) -> tuple[np.ndarray, int]:
    """Estimate the covariate coefficients of ``X`` conditional on the design.

    Regresses every column of ``X`` on ``[1, conditioning, covariates]`` by
    least squares and returns the covariate block of the coefficients
    (``q × p``) and the residual degrees of freedom ``n − 1 − k − q``.

    Raises
    ------
    ValueError
        If ``X`` and the design differ in rows, or the design does not have
        full column rank; the message names the design columns.
    """

    X_arr = np.asarray(X, dtype=float)
    if X_arr.shape[0] != design.n_samples:
        raise ValueError(f"X has {X_arr.shape[0]} rows but the nuisance design has {design.n_samples}.")
    M = design.matrix()
    rank = int(np.linalg.matrix_rank(M))
    if rank < M.shape[1]:
        raise ValueError(
            f"The residualization design [intercept, {', '.join(design.column_names)}] is not of full rank "
            f"(rank {rank} of {M.shape[1]} columns on {M.shape[0]} samples); a covariate is collinear with "
            "the conditioning design or with another covariate, or a factor level is absent."
        )
    coefficients = np.linalg.lstsq(M, X_arr, rcond=None)[0]
    k = design.conditioning.shape[1]
    return coefficients[1 + k :, :], int(M.shape[0] - M.shape[1])

    def residualize(
    X: Union[np.ndarray, pd.DataFrame],
    covariates: np.ndarray,
    coefficients: np.ndarray,
) -> Union[np.ndarray, pd.DataFrame]:
    """Subtract the fitted covariate part: ``X − covariates @ coefficients``.

    Only the covariate columns are read, so held-out rows can be residualized
    with training coefficients without their labels. A DataFrame keeps its
    index and columns.
    """

    shift = np.asarray(covariates, dtype=float) @ np.asarray(coefficients, dtype=float)
    if isinstance(X, pd.DataFrame):
        return X - pd.DataFrame(shift, index=X.index, columns=X.columns)
    return np.asarray(X, dtype=float) - shift

    def nuisance_partial_r2(X: Union[np.ndarray, pd.DataFrame], design: NuisanceDesign) -> np.ndarray:
    """Per-feature partial R² of the covariates given the intercept and conditioning.

    ``1 − RSS([1, D, C]) / RSS([1, D])`` for every column of ``X``: the share
    of the variance left after the conditioning design that the covariates
    explain, i.e. what the residualization removes. A column with no variance
    left after the conditioning design gets 0.
    """

    X_arr = np.asarray(X, dtype=float)
    full = design.matrix()
    reduced = full[:, : 1 + design.conditioning.shape[1]]
    rss_full = _residual_sum_of_squares(full, X_arr)
    rss_reduced = _residual_sum_of_squares(reduced, X_arr)
    with np.errstate(divide="ignore", invalid="ignore"):
        r2 = np.where(rss_reduced > 0.0, 1.0 - rss_full / rss_reduced, 0.0)
    return np.clip(r2, 0.0, 1.0)
